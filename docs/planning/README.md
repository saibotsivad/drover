# Planning Documents

The files in this folder are plans that the team is currently putting together.

- They may not be fully formed it ready for work, so don't start implementation without checking with the team.
- Planning files are ephemeral, they shouldn't be linked to from other files.

In general the flow for new features should be 

RFC -> Plan -> Implement

1. RFC - A general sketch or proposal, the goal being to get team buy-in on a big change before doing any significant planning or implementation. 
2. Planning - **(You are here)** A more concrete plan for implementing an RFC or some other internally proposed change that's been approved.
3. Implementation - Not a document that needs to live in the repository, outside of a long-lived feature branch.
